This file contains the instructions for running code for the expriements of paper "DeGLIF for Label Noise Robust Node
Classification using GNNs"

-> Sample code is provided for DeGLIF_sum and DeGLIf_mv

-> Folder data contains neccesary datasets, i.e., Cora, Citseer and Amazon Photo

-> Naming of ipynb files is as follows: Model name_datase. For example DeGLIF_sum_Cora means DeFLIF_sum implementation for Cora dataset.

#installation requirements
-> It is recomended to create a conda environment with the following:
  - `Python 3.7.11`
  - the necessary python packages versions are memtioned in `requirements.txt`, and can be installed using `Requirements.ipynb`.
